# Scene Ready Check

Preloads the next scene for everyone in **Foundry VTT** and shows the GM who is ready, so large maps are already there when the scene opens.

## Usage

1. Right-click a scene in the navigation bar or the Scenes tab and choose **Prepare for players**.
2. Watch each player's progress in the window that opens. Files that could not be loaded are listed there.
3. Click **Activate scene** when everyone is ready.

You can activate at any time, so a player with a slow connection never holds up the game. Closing the window stops the preparation. The normal way of activating scenes is unchanged.

## Settings

- **Activate automatically when everyone is ready:** a checkbox in the window, off by default
- **Language:** English or German

## Requirements

- Foundry VTT v12 (tested with build 343)

## Installation

In Foundry, go to **Add-on Modules → Install Module** and paste this manifest URL:

```
https://github.com/Xovio/foundry-scene-ready-check/releases/latest/download/module.json
```
